# Проверка приложения — 2026-10-21

Основание: локальные `docs/docs.md` и `docs/api.md`. Указания письма о публикации и отправке email проверялись как требования к сдаче, а не как разрешение выполнять эти действия.

## Исправлено

1. На ширине 320 px длинный адрес назначения выходил за границы кнопки. Для текста кнопок задана максимальная ширина 100%; повторная проверка не обнаружила горизонтального переполнения.
2. Локальное состояние формы Claim могло сохраняться при замене сессии. Компонент формы теперь пересоздается по session.id. В браузере проверено: введенная сумма 0.75 после успешной смены токена становится пустой, вход возвращает на Home.
3. README обновлен: больше не описывает Hello World.
4. Проверка API-контрактов добавлена в обычный `npm test`: endpoints, auth, строки сумм, cursor, idempotency key, нормализация ошибок, неизвестный результат POST и общий cooldown клиента.

## Автоматические проверки

- 52 теста: money, session, claims, balances policy, activity и API.
- TypeScript и ESLint.
- Expo Doctor: 20/20.
- `expo install --check` в offline mode: зависимости совместимы по локальным данным SDK; онлайн-проверка столкнулась с правами записи Expo cache. Expo Doctor отдельно прошел онлайн.
- Production web export.

## Оставшиеся требования к сдаче и ограничения

- Добавлены NOTES.md и ai-logs/: решения, три подтвержденных эпизода работы с AI, экспорт исходных сообщений и фрагменты QA tool log. Исходная беседа с двумя подходами к балансу сохранена (message-021).
- В README пока нет live link. Деплой и публичная доступность не проверены. Текущий server output нельзя считать готовым для произвольного static hosting без адаптации.
- `docs/docs.md` содержит личный токен и сейчас не отслеживается Git. Перед публичным коммитом документа необходима очистка; значение токена в этом отчете не приводится.
- Сохранение токена и Claim требуют доступного browser storage; безопасная отправка Claim использует Web Crypto и Web Locks, поэтому нужен современный браузер и HTTPS (localhost допускается для разработки).
- Проверка выполнена в desktop-браузере с изменением viewport. Настоящие Safari/iPhone, Android, экранная клавиатура, screen reader и физическое отключение сети не проверялись. Наличие unit-тестов сетевых ошибок не заменяет эти проверки.
- Сроки/периодичность коммитов, AI logs, публичный репозиторий, отправка письма и live deployment не подтверждены этой проверкой.
